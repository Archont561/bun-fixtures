---
title: Quickstart
description: Get up and running with bun-test-utils in 5 minutes.
---

In this quickstart, you will install `bun-test-utils`, initialize its preload, and compose your first Playwright-style fixture test.

## 1. Install & Initialize

```bash
bun add -d bun-test-utils
bunx bun-test-utils init
```

The `init` command adds the preload plugin to `bunfig.toml` and scaffolds an extendable `test.ts` module.

## 2. Compose Fixtures

Edit `test.ts` and add project fixtures with `test.extend()`:

```ts
// test.ts
import { test as base } from "bun-test-utils";
import { stdFixtures } from "bun-test-utils/std";

export const test = base.extend({
  ...stdFixtures,
  server: {
    scope: "session",
    setup: async (use) => {
      const server = await startTestServer();
      await use(server);
      await server.stop();
    },
  },
  user: {
    setup: async (use, { server }) => {
      const user = await server.insertUser({ name: "Ada" });
      await use(user);
    },
  },
});
```

## 3. Write a Test

Import the composed test from your local module:

```ts
// users.test.ts
import { expect } from "bun-test-utils";
import { test } from "./test";

test("finds created user", async ({ user }) => {
  expect(user.name).toBe("Ada");
});
```

Fixtures can depend on one another, have session, file, or test scope, and run teardown in reverse order.

## 4. Run Tests

```bash
bun test
```

There is no implicit fixture discovery. Every fixture available to a test comes from the explicit `test.extend()` chain imported by that test file.
